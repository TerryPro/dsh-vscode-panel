# 电商销售数据分析报告

- 数据区间：2024-01-02 ~ 2024-12-31
- 有效订单数：1,200 笔
- 总销售额：5,154,383 元
- 平均客单价：4,295.32 元

## 核心结论

1. **区域**：华东 贡献最高，销售额 1,593,337 元，
   占比 30.91%。
2. **时间**：销售峰值出现在 2024-12，全年呈下半年走高趋势
   （12 月较 1 月有明显增长）。
3. **品类**：手机数码 是销售额最高的品类。
4. **关联性**：销售额与数量、单价均强正相关；数量与单价几乎不相关。

## 建议

- 对高贡献区域加大投放，对“未知”区域补齐数据采集。
- 在旺季（Q4）前提前备货并锁定物流运力。
- 针对低客单价区间设计搭售组合，提升客单价。
